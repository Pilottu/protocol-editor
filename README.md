# Редактор протоколов (Python)

Переписанная на Python версия программы «Редактор протоколов» для эндоскопических исследований.
Лицензия

Внутренний проект МУЗ ГКБ № 2 г. Кемерово. Авторы оригинальной программы: Смирнов В.В., Беляев М.В.

## Возможности

- Создание, редактирование, удаление протоколов
- Работа с пациентами, врачами, заключениями
- Дерево исследований: Исследование → Пациент → Протокол
- Поиск и фильтры
- Работа с SQL Server / LocalDB
- Встроенный загрузчик и установщик SQL Server Express LocalDB
- Резервное копирование базы данных
- Подключение существующей базы (.mdf/.ldf) к LocalDB

## Требования

- Windows 10/11
- Python 3.9+ (64-бит)
- ODBC Driver 17 for SQL Server
- SQL Server Express LocalDB (устанавливается автоматически из встроенного загрузчика)
